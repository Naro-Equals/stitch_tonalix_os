## Brand & Style

This design system targets dedicated athletes, data-driven fitness enthusiasts, and daily performance trackers who demand instant, visceral biometric feedback. The visual language conveys precision, kinetic momentum, and calculated discipline.

The aesthetic fuses **Precision Dark Minimalist** with **Tactile Cyber-Athletic** nuances:
- **Atmospheric Depth:** Inky obsidian foundations eliminate ocular fatigue during high-intensity and low-light sessions.
- **Luminescent Telemetry:** Electric teal and cyan gradients act as functional energy meters, glowing with calculated luminescence rather than decorative excess.
- **Biometric Legibility:** Extreme typographical hierarchy separates rapid glanceable metrics from granular telemetry. Structural surfaces rely on muted dark framing, letting luminous biometric indicators slice cleanly through the interface.

## Colors

The palette establishes an absolute obsidian stage where luminous electric teal commands immediate visual priority.

### Surface Hierarchy
- **Base Canvas (`#0B0F14`):** The primary view surface; an abyss that maximizes display contrast and power conservation on OLED screens.
- **Surface Layer 1 (`#121820`):** Primary card substrates, floating navigation bars, and section plates.
- **Surface Layer 2 (`#1A222D`):** Elevated widgets, secondary interactive containers, chart plot areas, and hover state overlays.
- **Surface Layer 3 (`#242F3E`):** Segmented button wells, inactive progress tracks, and disabled interactive pills.

### Accent & Telemetry Palette
- **Kinetic Teal Primary (`#00F2C3`):** High-priority callouts, active metric highlights, target achievements, and primary CTAs.
- **Vibrant Cyan Secondary (`#00D1B2`):** Running velocity, cadence counters, secondary metric visualizations, and interactive toggles.
- **Muted Teal Tertiary (`#14B8A6`):** Supporting data axes, filled progress backgrounds, and secondary badges.
- **Critical Alert (`#FF4757`):** Heart rate threshold warnings, missed targets, and system alerts.

### Boundary Tokens
- **Borders & Dividers:** Subtle slate-blue `#222D3B` used at 1px thickness to define layout containers without visual clutter.

## Typography

Typography prioritizes rapid glanceability during motion. A dual-type engine combines mechanical geometry with utilitarian data clarity.

- **Display & Headlines (`Space Grotesk`):** Engineered character shapes bring technical dynamism to milestone headings and primary statistical outputs.
- **Narrative & UI Text (`Inter`):** Renders activity notes, tooltips, coaching suggestions, and body text with high legibility.
- **Biometric Telemetry & Labels (`JetBrains Mono`):** Dedicated to numerical units (BPM, Pace, kCal, VO2 max), timestamps, timestamps, and compact telemetry badges.

All numeric statistics (`stat-metric`, `data-mono-*`) must implement `font-variant-numeric: tabular-nums` to eliminate layout jitter during live-updating telemetry streams.

## Layout & Spacing

The interface is structured upon a fluid modular grid system calibrated for rapid scanning and dense data consumption.

### Breakpoints & Grid Rules
- **Mobile (< 768px):** 4-column layout, `1rem` outer canvas margin, `1rem` column gutters. Metric clusters stack vertically or group into 2x2 grids.
- **Tablet (768px - 1024px):** 8-column layout, `1.5rem` canvas margin, `1rem` gutters. Dashboard modules split between active timeline and statistical summaries.
- **Desktop (> 1024px):** 12-column layout with a maximum container limit of `1440px`, `2.5rem` canvas margin, `1.5rem` gutters. Displays synchronous multi-stream metric monitors side-by-side.

### Spacing Philosophy
- Use `space-2xs` (4px) and `space-xs` (8px) for tightly coupled label-to-value locks.
- Use `space-sm` (12px) and `space-md` (16px) for interior padding within cards, chips, and telemetry clusters.
- Use `space-lg` (24px) to `space-2xl` (48px) exclusively for inter-card gap spacing and macroscopic section breaks.

## Elevation & Depth

Visual hierarchy does not use diffuse dropshadows. Instead, this design system achieves spatial hierarchy via **Tonal Stepping**, **Glass Surface Occlusion**, and **Luminescent Atmospheric Back-Glows**.

### Tonal Stratification
- **Ground Floor (`#0B0F14`):** Canvas backdrop.
- **Mid-Tier (`#121820`):** Activity tiles and graph modules. Outlined with a fine 1px border (`#222D3B`).
- **Floating Overlays (`#1A222D` with 80% opacity):** Modals, metric inspectors, bottom sheets, and floating control navigation. Requires `backdrop-filter: blur(12px)`.

### Luminescent Energy & Consistency Glow
- **Active Focus:** Cards representing an active workout emit an electric-cyan aura: `box-shadow: 0 0 24px -4px rgba(0, 242, 195, 0.18)`.
- **Target Achieved / Streaks:** Consistency indicators and completed rings project a tight neon fringe: `filter: drop-shadow(0 0 8px rgba(0, 242, 195, 0.45))`.
- **Warning States:** Elevated heart rate zones swap glow tokens to crimson: `box-shadow: 0 0 20px -4px rgba(255, 71, 87, 0.25)`.

## Shapes

The interface balances aerodynamic curves with structural discipline.

- **Standard Containers (`rounded-md` / 0.5rem):** Metric tiles, graph plots, tabular item rows, and system input fields.
- **Card Enclosures (`rounded-lg` / 1.0rem):** Primary workout cards, hero analytics panels, summary sections, and popover panels.
- **Pills & Capsular Elements (`rounded-full` / 9999px):** Target-zone badges, status tags, toggle switches, activity filters, and primary action buttons.
- **Micro-Shape Radii (`rounded-sm` / 0.25rem):** Progress bar fills, streak calendar cubes, and micro telemetry tags.

## Components

### Buttons
- **Primary Kinetic Action:** Background `#00F2C3`, text `#0B0F14` in `Space Grotesk` 600 weight. Pill-shaped (`rounded-full`), padded with `space-sm` vertical and `space-xl` horizontal. Hover elevates luminance to `#33F5CF` with an outer glow: `0 0 16px rgba(0, 242, 195, 0.3)`.
- **Secondary Ghost Action:** Background transparent, 1px border of `#00F2C3`, text `#00F2C3`. Hover transitions background to `rgba(0, 242, 195, 0.08)`.
- **Tonal Auxiliary Button:** Background `#1A222D`, border 1px solid `#222D3B`, text `#FFFFFF`. Hover changes border to `#00D1B2`.

### Activity Cards
- Background `#121820`, 1px border `#222D3B`, radius `1rem`, internal padding `space-lg`.
- Top-anchored metadata row: Category tag (`label-caps`) on the left, live indicator or icon on the right.
- Central zone: Large quantitative metric (`stat-metric`) paired with a micro unit descriptor (`JetBrains Mono`).
- Footer zone: Micro chart canvas or timeline progress indicator.

### Consistency & Ring Indicators
- Multi-day streak trackers display as a horizontal sequence of rounded micro-squares (`0.25rem` radius). Inactive days use `#1A222D`; active days use `#00F2C3` with an inline cyan radial highlight.
- Radial circular gauges use track color `#1A222D` with a stroke cap of `round` and active telemetry drawn in linear gradients from `#00D1B2` to `#00F2C3`.

### Input Fields & Controls
- Form inputs feature `#121820` fill, 1px `#222D3B` boundary, text color `#FFFFFF`, and monospace placeholders in `#526173`.
- Focus shifts the boundary to `#00F2C3` alongside an inner glow: `0 0 0 1px #00F2C3`.

### Checkboxes & Radio Elements
- Custom circular radios and squircle checkboxes (`0.25rem` radius). Unchecked state uses a 1.5px border `#242F3E` on `#121820`. Checked state replaces the surface with `#00F2C3` carrying an obsidian `#0B0F14` check icon or dot.

### Telemetry Chips
- Compact pills styled with `#1A222D` fill and `0.06em` letter-spaced monospace typography. When displaying status (e.g., "GPS LOCKED", "Z4 THRESHOLD"), they include a leading 6px glowing LED-style indicator dot.
